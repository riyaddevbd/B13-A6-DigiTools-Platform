DigiTools – Digital Tools Buying Platform

Project Description

A-6 Digital Tools Buying Website is a modern e-commerce web app built with React.js and Tailwind CSS.  
It allows users to explore digital products, view detailed features, and add items to a dynamic cart system.  
The application includes real-time cart updates, product toggling, and toast notifications using React-Toastify.  
Users can easily manage their cart, remove items, and proceed to checkout with a smooth UI experience.  
The project is fully responsive and designed following Figma guidelines for a clean and user-friendly interface.


Technologies Used
- React.js  
- Tailwind CSS, DaisyUI 
- JavaScript (ES6+)  
- React-Toastify (NPM Package)  
- JSON (for product data)  

Key Features

*** Add to Cart Functionality Users can add products to the cart with instant toast notifications. Duplicate items are prevented with warning alerts.

*** Remove & Checkout System

*** Product & Cart Toggle A toggle system allows users to switch between product view and cart view dynamically, with real-time cart count updates.
